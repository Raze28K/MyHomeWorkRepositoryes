# UI-переупаковка проекта

Учебный проект с пользовательским интерфейсом на **Material UI (MUI)**. Бизнес-логика (Redux, маршрутизация, авторизация, магазин, лайки) сохранена без изменений.

## Выбранная библиотека

**Material UI (MUI)** — компоненты форм, модальных окон, карточек, навигации и типографики. Используется единая тема (палитра, типографика, скругления). Кастомный CSS не используется (только базовый сброс в `index.css`).

## Структура проекта

```
src/
├── app/
│   └── store.js           # Redux store (auth, shop, likes)
├── components/
│   ├── Layout.jsx         # AppBar, навигация, контент, Footer, адаптивное меню
│   ├── ProtectedRoute.jsx # Защита маршрутов по авторизации
│   ├── Modal/
│   │   └── Modal.jsx      # MUI Dialog для модальных окон
│   ├── ProductCard/
│   │   └── ProductCard.jsx# Карточка товара (MUI Card)
│   ├── Search/
│   │   └── Search.jsx     # Поле поиска (MUI TextField)
│   ├── LikeButton/
│   │   └── LikeButton.jsx # Кнопка лайка (MUI Button + иконки)
├── data/
│   └── products.js        # Загрузка списка товаров
├── features/
│   ├── auth/              # Слайс и селекторы авторизации
│   ├── likes/             # Слайс и селекторы лайков
│   └── shop/              # Слайс и селекторы магазина (поиск, загрузка)
├── pages/
│   ├── Login.jsx          # Вход: форма с валидацией (email, пароль)
│   ├── Feed.jsx           # Лента (список активности)
│   ├── Shop.jsx           # Магазин: поиск, сортировка, карточки товаров
│   ├── ProductPages.jsx   # Страница товара, лайк
│   └── Profile.jsx        # Профиль, модальное окно редактирования
├── theme.js               # Тема MUI (палитра, типографика)
├── App.jsx                # Маршруты
└── main.jsx               # Точка входа, ThemeProvider, CssBaseline
```

## Запуск

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Реализованные требования

- **Layout**: AppBar с навигацией, основной контейнер, Footer, выдвижное меню на мобильных.
- **Страницы**: Лента, Магазин, Страница товара, Профиль — оформлены компонентами MUI, единый стиль и типографика.
- **Формы**: Login и форма редактирования профиля — MUI TextField/Button, валидация (обязательные поля, email, длина), отображение ошибок.
- **Модальные окна**: MUI Dialog в компоненте Modal; на Профиле — «Редактировать профиль» (создание/редактирование данных с валидацией).
- **Списки и карточки**: Магазин — карточки товаров (MUI Card), поиск (фильтр) и сортировка (Select). Лента — список (MUI List).
- **Адаптация**: навигация переключается в drawer на узких экранах, сетка карточек и формы адаптируются под ширину.
